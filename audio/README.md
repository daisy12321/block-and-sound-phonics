# Block & Sound audio

These MP3 files are isolated phoneme clips recorded by the project owner for
the Block & Sound game. The original recording and WAV editing masters are not
included in this website package.

## Processing

- Example phrases such as “as in …” were removed.
- Each file contains only the isolated phoneme spoken before the example.
- The clips are mono, 44.1 kHz MP3 files at 96 kbps.
- Processing includes a gentle 65 Hz high-pass filter, loudness matching, and
  short edge fades.
